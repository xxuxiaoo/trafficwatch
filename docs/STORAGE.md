# 存储管理

打开流量中心左下角的**存储管理**。本机采集、Clash 和诊断各自写入本机 SQLite WAL。摘要缓存与原始历史分开保存。

近期样本和分钟连接记录留在普通表内。默认超过 90 天的记录按自然月压缩，可改为 30、180 或 365 天，也可暂停自动整理。整理保留进程、目标、字节、时间和全部分钟精度。每个压缩块核对行数和 SHA-256，在写入压缩块的同一事务内移走原行。打开旧日期时只读取涉及的块。

自动整理在查看服务启动后和每 6 小时检查，分批处理，关闭网页不取消。清理摘要缓存后，会按需从历史重建。空页可复用，也可将支持增量回收的数据库的空页分批归还给磁盘。较早的明文数据库可能只支持复用空页，页面会明确显示。

存储快照显示历史、诊断、缓存和旧版恢复文件。空页已计入 SQLite 文件大小。月度压缩率反映数据内容，不包含文件页、索引或 WAL 开销。无限保留仍会增长，增长估算至少需要一天的样本。

旧版加密文件由升级工具保留，详见[原位升级](BUILD_WINDOWS.md#in-place-upgrade)。
