# 本地加密与 AI 访客卡

加密是可选功能。**安装新版不等于历史已经加密。** 必须由电脑的安装账户在本机设置密码，完成原历史迁移、备份恢复验证以及旧明文清理，页面才显示保护已完成。密码和恢复码都不要发送给 AI 或放进命令参数。

## 本人如何使用

1. 桌面 TrafficWatch 控制台 → **设置加密 / AI 访客卡**。
   控制台会用 Windows 的默认浏览器打开隐私页；启动失败会显示原因。仅含事件代码的启动日志位于 `%LOCALAPPDATA%\TrafficWatch\logs\privacy-launch.log`，不记录设置凭据或密码。
2. 首次设置至少 10 个字符的密码，并将页面仅显示一次的恢复码保存到安全位置。恢复码与密码拥有同等的解锁能力。
3. 等待原有历史加密完成，执行页面上的 **验证并清理项目旧明文**。提交后立即返回，后台显示快照、复制、完整校验和清理阶段。大库校验可能持续数分钟，关闭或刷新页面不取消任务。全部来源的备份验证成功后，才清理当前数据目录的旧 `monitor.sqlite`、WAL 和旧摘要缓存。重复点击复用正在运行的任务；中断后可解锁重试，已验证的加密备份可复用。
4. Windows 锁屏后，流量界面会锁定；解锁 Windows 后仍需重新输入流量密码。开机采集和无限保留不受影响。
5. **立即锁定界面**遵循各 AI 卡的锁屏设置；**锁定并撤销全部 AI**立即关闭所有访客卡及后台解密会话。

普通解锁只需等待加密数据库打开；已有历史与实时采集状态随即可看。锁定期间积压的密文记录按来源轮流、限时分批导入，不阻塞总览与 AI 连接诊断，页面单独提示“后台补齐”。准备或空间维护中的暂不可用响应不会清除本次登录。同一浏览器的同一用户配置下，切换总览、诊断、存储和旧版详情，关闭标签页后从托盘重新打开，或退出并重开浏览器，都可沿用有效的本次解锁；重新打开前必须经过服务端本人会话校验。

浏览器只保存本次解锁的临时访问凭证及其到期时间，不保存密码、恢复码、历史解密密钥或已解密记录。本人会话最长 12 小时，重新打开页面不会延长有效期。Windows 锁屏、注销、主动锁定、会话到期或界面服务重启后，旧凭证失效，需要重新输入密码；解锁 Windows 本身不会解锁流量记录。锁屏时关闭着浏览器，重新打开时也会检查并清除旧凭证。另一个浏览器、无痕窗口或其他浏览器用户配置没有这个会话，需各自解锁。

旧的两个页面保留。启用加密后，它们从同一流量中心的 `/legacy?lane=windows` 或 `/legacy?lane=clash` 查看，并使用相同的解锁状态。采集端旧历史接口拒绝直接读取加密历史。

## 给 AI 授权

AI 首先运行安装目录的命令：

```powershell
& 'C:\Program Files\TrafficWatch\TrafficWatch-AI.cmd' request --name '排查最近梯子流量'
```

本人打开 **隐私与 AI 访客卡**，选中该申请，配置：

| 设置 | 行为 |
| --- | --- |
| 数据来源 | 本机应用、Clash，或两者；Harness 包含在进程归因结果中 |
| 日期范围 | 最近 1 / 7 / 30 天、所有历史、不连续的指定日期，或一个以上自定义分钟时段 |
| 有效期 | 30 / 60 / 120 分钟或 1–10080 分钟自定义 |
| 查看、导出 | 独立授权；导出也受日期及来源限制 |
| 增、改、删 | 分别表示添加、修改和删除排查备注 |
| 删除原始历史 | 额外的高权限开关；只删除授权日期内的原始记录，无法撤销 |
| 修改分组规则 | 独立权限，明确影响全局 Harness 分组，不能伪装成仅修改某一天 |
| 锁屏后继续 | 本人界面上锁，已有该卡仍可在有效期内继续访问授权范围 |
| 与本人解锁联动 | 本次解锁期间，按当前模板自动批准新申请；锁屏后停止自动批准 |

“最近几天”和“所有历史”固定到发卡时刻；指定日及自定义时段可以覆盖该范围内随后采集的记录。所有日期按北京时间，区间结束时间不包含在范围内，精度为一分钟。不相邻的日期保持分离；查询整周总量也不会混入中间未授权的一天。

本人批准后，AI 运行：

```powershell
& 'C:\Program Files\TrafficWatch\TrafficWatch-AI.cmd' claim
& 'C:\Program Files\TrafficWatch\TrafficWatch-AI.cmd' status
& 'C:\Program Files\TrafficWatch\TrafficWatch-AI.cmd' overview --range all
& 'C:\Program Files\TrafficWatch\TrafficWatch-AI.cmd' detail --lane clash --range all
& 'C:\Program Files\TrafficWatch\TrafficWatch-AI.cmd' detail --lane clash --range all --process synthetic.exe --page 1
```

`--profile task_name` 可为不同排查任务保存不同卡片。密码、恢复码和访客令牌不输出到终端，也不通过聊天转交。领取后的令牌由当前 Windows 用户的 DPAPI 保护，保存于 `%LOCALAPPDATA%\TrafficWatch\ai`；不能仅凭复制文件在另一账户/另一电脑使用。会话重启后服务端不再认可旧卡。

备注使用 `create / update / delete-note --lane clash --input <JSON 文件>`。JSON 形式为 `{"note":{"at":时间戳,"title":"标题","body":"备注内容","id":"修改或删除时填写"}}`。查询备注：`notes --lane clash`。有额外授权时，`delete-history --input <JSON 文件>` 接受 `{"lane":"clash","windows":[{"from":开始时间戳,"to":结束时间戳}]}`。任意 JSON 文件不能执行 SQL 或指定文件路径。

每个 API 请求都检查令牌、来源、操作和到期时间；返回长查询结果前再次验证。历史查询连接先建立日期受限的临时视图，禁止 AI 查询复用全局摘要缓存。无法用跨日期合计、分页或导出绕过限制。访问申请名称只是标签，不作为程序身份凭证。

## 保护方式与边界

- 密码通过 Argon2id（64 MiB、3 次、并行度 2）派生包装密钥；密码和离线恢复码分别通过 AES-256-GCM 保护随机主密钥及历史私钥。修改密码只重新包装密钥。
- 历史库、WAL、摘要缓存及加密备份使用 SQLite3MultipleCiphers 的 ChaCha20-Poly1305 页加密。临时查询表放在内存；解密历史不写入浏览器 localStorage。
- 采集器只有历史公钥。锁定期间采集到的应用、地址、会话和字节数封装为加密包，持久保存到 SQLite 队列；解锁后由工作线程导入加密历史。包有独立签名，导入编号与字节变更同事务提交，崩溃重试不会重复计费。公开偏好只包括采集模式、保留天数、阈值和明确配置的进程分组，不包括观察到的流量历史。
- Windows 会话检测由独立本地助手完成；未知状态或检测助手失联会关闭解密会话。注销、重启、挂起/休眠会撤销所有卡。锁屏后继续需本人明确勾选，其代价是后台在该卡到期前仍保留受控解密能力。日期限制属于服务端权限策略，不能宣称是“只有这几天的密码学密钥”。
- 保护目标是项目数据文件被复制后的离线读取，以及未授权界面/API 访问；不承诺抵抗已控制当前 Windows 账户、管理员、进程内存读取或恶意浏览器扩展。JavaScript、操作系统分页和休眠文件不能保证秘密字节被完全擦除。
- 清理仅覆盖当前项目管理的数据文件，不自动删除用户 Excel、截图、导出、其他路径下的手工备份或旧电脑备份。普通删除也不等于磁盘取证级擦除；系统磁盘加密是独立的补充保护。
- AI 已经获得的结果可能保存在聊天和工具输出中。撤销卡片阻止后续访问，无法收回已交付结果。
- 密码和恢复码同时丢失时，无法恢复历史。采集仍可继续封装，但不能绕过加密读回这些记录。

## 验证与维护

0.9.0 增加[存储管理](STORAGE.md)：默认将 90 天前的样本与分钟连接明细按月无损压缩后保存在加密库内，所有历史继续无限保留。旧日期与 AI 卡按原权限透明查询；缓存有独立限额，空间回收临时文件也明确加密。整理、占用和回收操作仅本人会话可使用。

`npm ci --ignore-scripts` 后使用 Node.js 24 执行 `npm run check`、`npm test`。安全测试覆盖错误密码、修改密文、错误数据库密钥、非连续日期隔离、权限、锁屏保留策略、注销撤销、采集命令签名和重放、加密迁移、重复导入、API 和分页合计。真实密码只在用户本机输入，不属于自动测试。

首次切换前停止旧版本写入；新采集器确认使用加密队列后，迁移线程才读取固定的旧数据。迁移按批提交游标，锁定或异常后可续传。原始文件在迁移及加密备份验证完成前保留。无法验证时显示未完成，不清理原数据。
