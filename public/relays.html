添加新的中转域名后，TrafficWatch 会备份当前列表，使用物理网卡 DNS 解析，更新精确 IPv4 路由和 Clash 排除项，再核验连接路径。域名有未覆盖的 IPv6 地址时不会标记为“绕行已验证”。勾选项以外的目标不会设置绕行。

备份与恢复

每次保存或删除之前都会备份完整列表；恢复备份会先保留当前版本。

路径如何生效与撤回

应用操作会刷新 DNS、Windows 精确物理路由、当前 Clash 的 TUN 排除和 DIRECT 规则，以及该目标的代理例外。后台在列表保存后自动校验；也可手动点击“校验并应用”。路由按目标 IP 生效，和中转共用同一 IP 的其他网站也可能从该网卡出站。

已建立的连接需要重连才能使用新路径。如果网关显式指定 Clash 为上游代理，还需要在网关中将相应中转设为直连；新添加的 NO_PROXY 例外通常需要重启网关后生效。列表不需要填写 API 密钥。

停用或删除的目标会从受管列表和新连接配置移除，后台按核验结果清理由 TrafficWatch 创建的路由与配置。点“恢复所选备份”可重新加入先前的列表。“恢复原 DIRECT”会自动备份当前列表、停用全部目标并撤回 TrafficWatch 管理的绕行配置，保留其他 Clash 规则。
