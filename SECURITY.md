# Privacy and security

TrafficWatch keeps network history in plaintext SQLite files using WAL. The installed history folder is limited by Windows ACLs to the owner, SYSTEM and Administrators. The loopback viewer does not ask for a password. Records can include process names and paths, destination IPs/domains, connection times, route metadata, byte counts and process-family evidence. The inherited optional session feature can read local Codex activity/token metadata; it does not convert token counts into network bytes.

The Windows process observer examines limited executable/script arguments in memory to classify supported Node-based harnesses. It does not export full command lines, trailing CLI arguments, environment variables or chat bodies into those observations. The Mihomo controller secret is read from local configuration/environment and must remain private.

The default HTTP services bind to `127.0.0.1` and validate Host/Origin and the application request header. These checks do not isolate mutually untrusted users on the same machine. Do not expose the services with a reverse proxy or port-forward them to other machines.

System-wide ETW collection uses an administrator-installed SYSTEM boot task. Executable files remain under Program Files; observations and the disposable viewer cache live separately. Ordinary collection only reads its observation sources. The optional relay-bypass feature, when explicitly configured and enabled, changes managed physical IPv4 routes, a marked hosts block and the configured Clash enhancement script; its rollback removes the managed changes. TrafficWatch does not install TLS interception, decrypt HTTPS or send application telemetry. Manual release checks contact GitHub. Windows builds download pinned official Node.js and diagnostic NuGet dependencies when verified local copies are unavailable.

AI diagnostics import only allowlisted error, retry, timing and network metadata from supported local logs; they do not retain prompts, response bodies, credentials or full raw log lines. Background relay probes make small unauthenticated HTTPS requests to configured endpoints. TraceEvent records TCP metadata; PktMon is configured for filtered component/counter metadata without packet contents. Incident ETL files briefly exist in an access-restricted working directory before insertion into the local diagnostic database and removal. See [connection diagnostics](docs/connection-diagnostics.md) for collection bounds, source checks and managed bypass behavior.

Do not publish `config.local.json`, `suite-settings.json`, `.env`, raw exports, screenshots of real use, databases, logs, crash dumps, credentials or build caches. `.gitignore` and `scripts/audit-publication.mjs` provide a first check, not a guarantee of complete secret detection. Inspect a public diff as well.

For a suspected vulnerability, avoid posting real connection records or credentials in a public issue. Use GitHub's private vulnerability reporting when available; otherwise describe the issue without sensitive evidence and request a private contact channel.
